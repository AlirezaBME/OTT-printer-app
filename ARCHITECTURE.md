# Architecture

`MainActivity` hosts Compose and handles single content-URI PDF/image intents. `MainViewModel` owns the selection, language preference, bounded snapshots, preview and UI job manager. Imports and renderer access are serialized; an invalid import leaves the previous document usable.

`LbpOtgApplication` owns one `UsbDeviceRepository`. Its operation mutex serializes all device opens, claims, probes, writes and closes across the UI and Android PrintService. The permission manager matches device identity and coalesces requests. Only printer-class interfaces using USB protocol 1 or 2 and a bulk OUT endpoint are eligible.

`DocumentSource` owns its input and supports previews, print rendering, duplication and close. PDFs render directly into one paper bitmap using physical PDF point units for Actual Size. Images import once, sample to bounded dimensions and correct EXIF orientation. Test pages use on-device drawing. `DitherEngine` converts a bitmap to a packed monochrome raster using three error scanlines.

`PrintJobManager` validates settings, locks USB ownership, checks printer language/status before rendering, spools Canon NCAP/CPCA or PCL data to a bounded temporary file, and uses negotiated Canon MLP frames or bounded PCL USB chunks. Copies are expanded in document order. A manager rejects overlapping submissions rather than replacing an active job. Cancellation releases ownership in a non-cancellable finally block and explicitly warns that previously transmitted pages may still print. A failed write is not automatically retried, avoiding duplicate physical output. `Completed` is only an offline file-export result. `TransferComplete` keeps printer acceptance, processing and physical output UNKNOWN; the Android PrintService blocks an unconfirmed submission instead of marking it complete.

`RawPclEncoder` implements uncompressed PCL 5 raster pages with per-page media/orientation/resolution/dimensions and raster start/end commands. `CanonNcapEncoder` independently serializes the supported LBP6030 model NCAP grammar, two-bit 600-DPI raster and small SLIM bands. `CanonCpca` wraps PDL in the official driver's response-free print-stream mode with bounded packet lengths, setup and job termination. `DriverRegistry` resolves Automatic only against an explicit supported Canon identity or PCL 5 advertisement; CARPS2 and unknown printers fail before rendering. Official Canon binaries are used solely as external test oracles.

`DocumentPrintAdapter` owns a separate snapshot. It handles layout, requested page subsets, write cancellation and finish cleanup, producing PDFs incrementally with a bounded writer for Android's standard print dialog. Only one bitmap/JPEG is held at a time; output is capped at 256 MB and 10,000 pages. `LbpPrintService` handles sequential system jobs on the main framework thread, uses the shared USB lock, and advertises only supported Canon identities or printers whose probed language includes PCL 5.

Diagnostic/print-stream exports use a FileProvider restricted to `cache/exports`. The app has no Internet permission, no analytics/backend, and disabled cloud backup. Release signing is configured only by environment variables.

`RawPrnPrintSource` owns a bounded immutable snapshot and fingerprint; its spool copy is verified without rendering or encoder selection. `CanonPrintJobTransport` accepts opaque job bytes, verifies their transmitted body hash and owns the session lifecycle. `CanonMlpSession` implements native-reference channel/control framing and device service lookup. `CanonCpcaSession` passively assembles responses without fabricated status RPCs. USB ownership stays claimed through a bounded observation period, documented port-status polling and passive IN capture. `ProtocolCapture` records deterministic event fields, negotiated channels and optional exact binary streams; export is off the UI thread. See CANON_ISOLATION.md for evidence classifications and the hardware decision test.
